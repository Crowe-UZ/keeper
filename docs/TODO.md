# Что чиним и улучшаем

Список собран 2026-10-11 из пяти разборов (скачивание, распознавание, расширение, сервер, продукт).
Здесь только улучшения того, что уже есть. Новые функции — в [IDEAS.md](IDEAS.md).
Порядок: надёжность → качество текста → удобство → остальное. Сделанное отмечается галочкой.

## Уже сделано из разборов

- [x] «Только текст» и «только звук» не качают самое тяжёлое видео
- [x] «Видео + текст»: текст распознаётся параллельно со скачиванием и не занимает место в очереди
- [x] Ограничение качества — предпочтение, а не фильтр (вертикальные видео, «нет такого разрешения»)
- [x] При равном разрешении — H.264 + AAC; звук в `.m4a` без пережатия
- [x] Общий запас соединений на все загрузки, пауза перед повтором куска, пропавший кусок — ошибка
- [x] Временная папка своя у каждой запущенной копии
- [x] В файлы с курсов не пишется ссылка плеера с номером пользователя
- [x] Название видео больше не может выполниться как команда в уведомлении Windows
- [x] Тексты без технических слов; убраны подсказки-шум
- [x] Лог задачи без мусора, со списком форматов

## 1. Надёжность

- [x] 1.1 Вторая копия не может занять тот же порт; запуск не ждёт обновления yt-dlp (до 90 с)
- [x] 1.2 Распознавание не зависает на повреждённом файле; ожидание очереди на распознавание отменяется
- [x] 1.3 Модель распаковывается атомарно; докачка после обрыва; сверка контрольной суммы
- [x] 1.4 После F5 и перехода по сайту старые видео не остаются в списке; редиректы и ошибки не считаются потоками
- [x] 1.5 `install.bat` проверяет каждый шаг и честно сообщает об ошибке; инструкция ведёт на нужный Python
- [x] 1.6 Задачу не могут взять два обработчика; двойной щелчок не ставит дубль
- [x] 1.7 «Скачать со всех вкладок» берёт только вкладки с видео и не трогает cookies остальных сайтов
- [x] 1.8 Ошибки в обработчиках запросов пишутся в журнал; кривой запрос не оставляет задачу «в очереди» навсегда
- [x] 1.9 Локальный адрес качалки: проверка `Host`, только своё расширение, изменяющие запросы — POST
- [x] 1.10 Отмена действует и после скачивания (склейка, звук из видео); недописанный звук не остаётся в папке
- [x] 1.11а При выходе новые задачи не принимаются молча (ответ «закрываюсь, повтори»)
- [x] 1.11б Cookies не остаются во временной папке после грубого выхода; ffmpeg не переживает аварию программы
- [x] 1.12 Повтор «с cookies» — только при отказе во входе, а не после любой ошибки
- [x] 1.13 Собственные понятные сообщения не подменяются общими (свой тип ошибки)
- [x] 1.14 `settings.json` и `history.json` пишутся атомарно
- [x] 1.15 Имена файлов: зарезервированные имена Windows (CON, NUL…), длина пути, суффикс «— видео N» не срезается
- [x] 1.16 Окно выбора папки — отдельным процессом, одно за раз, с проверкой записи
- [x] 1.17 Временная папка называется по-своему (`.keeper-tmp`), чужая `.tmp` не трогается

## 2. Качество текста

- [x] 2.1 Куски речи склеиваются в отрезки по 15–22 с перед распознаванием
- [x] 2.2а Детектор речи Silero v6 вместо v4
- [x] 2.2б Порог детектора 0,35 против 0,5 сравнён на записи урока (169 с): 390 слов в обоих случаях — оставлен 0,5; на шумной записи не мерили
- [x] 2.3 Фильтр коротких обрывков и «Mmm.»-мусора; «речи не нашлось», если слов меньше трёх
- [x] 2.4 Модель выгружается из памяти после простоя
- [x] 2.5 Стыки кусков: строчная буква после принудительного разреза; потолок длины абзаца
- [x] 2.6 Слишком длинный кусок (пение, речь поверх музыки) делится на части
- [x] 2.7а Болгарская речь не принимается за русскую (в длинной пробе нет букв «ы, э, ё»)
- [x] 2.7б Проба языка не с самого начала записи (заставка, приветствие на другом языке)
- [ ] 2.7в Русскому пользователю при «авто» не нужна большая многоязычная модель только ради определения языка
- [x] 2.8 Число потоков — по числу ядер; версия sherpa-onnx закреплена
- [x] 2.9 Блок «Лицензии» (Parakeet — CC-BY-4.0, GigaAM и Silero — MIT, sherpa-onnx — Apache-2.0)

## 3. Удобство

- [x] 3.1 Окно: настройки над кнопкой, сообщения сразу под ней, редкое — в «Ещё»
- [x] 3.2 Раздел настроек: формат видео, звука и текста, качество, язык речи, папка
- [x] 3.3 Частичный успех: видео скачано, текст не получился — это не «ошибка» всей задачи
- [x] 3.4 Текст (или звук) к уже скачанному видео — без повторной загрузки
- [x] 3.5 Сбой загрузки не удаляет докачанное: «Повторить» продолжает с того же места
- [x] 3.6 Служебные страницы (`chrome://`, PDF): понятное «здесь качать нечего»; кнопка блокируется на время отправки
- [ ] 3.7 Очередь обновляется на месте, без полной перерисовки раз в секунду; управление с клавиатуры
- [x] 3.8 Уведомление «речи не нашлось» и честный заголовок при частичном результате
- [x] 3.9 Одни и те же слова везде: «Открыть папку», «Открыть файл», «Показать в папке»

## 4. Остальное

- [ ] 4.1 Расширение не обрабатывает каждый запрос каждой вкладки (фильтр по типам), не хранит чужие заголовки
- [ ] 4.2 Сегменты и служебные файлы не попадают в «видео»; лимит потоков не вытесняет главный
- [ ] 4.3 Плейлист, который не удалось прочитать, не превращает одно видео в несколько
- [ ] 4.4 Номер видео в имени файла и в «уже скачано» устойчив (ключ потока, а не порядок)
- [ ] 4.5 Ключ потока: разные видео с разными `?id=` не сливаются
- [ ] 4.6 Скан страницы не делает лишней работы; первая отрисовка окна не ждёт скана
- [ ] 4.7 Признак защиты от копирования — у конкретного видео, а не у всей вкладки
- [ ] 4.8 Ошибки записи в хранилище расширения пишутся в журнал
- [ ] 4.9 Старые логи задач удаляются; cookies не хранятся в памяти после завершения задачи
- [ ] 4.10 Одна классификация потока вместо двух; коды состояний отдельно от подписей
- [x] 4.11а Тесты: проверка запроса, один обработчик на задачу, модели, уведомление, форматы, склейка речи; сквозной тест без интернета
- [ ] 4.11б Тесты: живые запросы к программе (чужой адрес, нет заголовка), имена файлов Windows, история, группировка потоков в расширении
- [ ] 4.12 README: скриншоты установки, «папка, куда распаковал», строки про «речи не нашлось»
