# Keeper

Расширение для Chrome: скачивает видео с открытой вкладки в лучшем качестве — а ещё звук отдельно и текст того, что в видео говорят.
Работает с YouTube, VK, Rutube, TikTok, Instagram и ещё с тысячей сайтов, а также с уроками купленных курсов.
Только для Windows.

## Установка (один раз, 3 минуты)

1. Скачай **[Keeper-Setup.exe](https://github.com/Crowe-UZ/video_downloader_from_chrome/releases/latest)** — файл в разделе **Assets**, около 100 МБ.
2. Запусти его. Windows спросит, точно ли запускать программу неизвестного издателя: нажми **Подробнее → Выполнить в любом случае**. Так бывает со всеми программами без платной подписи.
3. Пройди шаги установщика. Он объяснит, что ставит, спросит папку и предложит сразу скачать распознавание речи для текста.
   Python и ffmpeg ставить не нужно — они внутри.
4. В конце откроется страница с последним шагом: в Chrome открой `chrome://extensions`, включи справа вверху
   **Режим разработчика**, нажми **Загрузить распакованное расширение** и выбери папку `extension` из папки программы
   (точный путь будет на этой странице).
5. Нажми на значок пазла справа от адресной строки и закрепи Keeper булавкой.

Обновление — скачай новый установщик и запусти поверх: настройки, история и скачанные модели останутся.
Удаление — «Параметры → Приложения» Windows.

<details>
<summary>Другой способ: без установщика, из исходников</summary>

1. Установи **Python 3.10 или новее** с [python.org](https://www.python.org/downloads/). В установщике поставь галочку **Add python.exe to PATH**.
2. Установи **ffmpeg** (склеивает видео и звук). Нажми `Win + R`, вставь строку и нажми Enter:
   ```
   winget install Gyan.FFmpeg
   ```
3. Скачай программу: зелёная кнопка **Code → Download ZIP** вверху страницы. Распакуй папку туда, где она будет лежать всегда.
4. В распакованной папке дважды щёлкни **`install.bat`** и дождись слов `everything is installed`.
5. Добавь расширение в Chrome, как в шаге 4 выше: папка `extension` лежит в распакованной папке.

Папку после установки не переноси. Если перенёс — запусти `install.bat` ещё раз.

</details>

## Как пользоваться

1. Открой страницу с видео.
2. Нажми на значок Keeper.
3. Отметь, что нужно получить, — одно или сразу несколько:
   - **🎬 Видео** — файл `.mp4`;
   - **🎵 Звук** — звуковой файл;
   - **📝 Текст** — файл `.txt` с тем, что говорят в видео.
4. Нажми **⬇ Скачать**.

На каждую отметку получается один файл. Выбор запоминается.

Готовый файл появится в папке `Загрузки\Videos`. Папку можно поменять кнопкой **Сменить**.

Запускать ничего не нужно: программа включается сама и сама выключается, когда качать нечего.
Пока она работает, у часов виден её значок — через него можно открыть папку с видео или выйти.

Ещё в окне:

- **⚙ Настройки** (шестерёнка вверху): в каком виде сохранять.
  - Видео — «MP4, играет везде» или «Максимальное качество»; рядом — не качать крупнее, чем нужно (например, «до 720p»).
  - Звук — «M4A, без потери качества» или «MP3».
  - Текст — обычный, с отметками времени или субтитры `.srt`; рядом — язык речи (обычно хватает «сам»).
  - Папка, куда складываются файлы.
- У загрузки есть **✕ Отмена**, у неудачной или отменённой — **↻ Повторить**. После сбоя «Повторить» продолжает с того места, где оборвалось.
- Видео уже скачано, а теперь понадобился текст или звук? Отметь нужное и нажми «Скачать»: они сделаются из файла на диске, заново ничего не качается.
- То, что уже скачано, второй раз не качается: программа предупредит и предложит **Скачать ещё раз**.
- Когда всё готово, Windows покажет уведомление с кнопками **Открыть файл** и **Показать в папке**.

### Про текст

Речь распознаётся на твоём компьютере, в интернет ничего не отправляется. Если нужен только текст, само видео не скачивается — качается одна звуковая дорожка, и после распознавания она удаляется.

В первый раз программа сама скачает модель распознавания: около 170 МБ для русского и около 490 МБ для английского и других европейских языков (при «Определить автоматически» нужны обе). Это разово.

Поддерживаются русский, английский и ещё 24 европейских языка. Азиатские и другие языки пока не поддерживаются.

### Если это урок курса или сайт, которого качалка не знает

Сначала **включи видео (▶)** и дай ему поиграть пару секунд, потом нажимай на значок.
На значке появится зелёная цифра — значит, видео поймано.

### Если на странице несколько видео

В окне будет список по порядку: «Видео 1», «Видео 2»… — с кадром из видео и названием, если оно подписано на странице.
У каждого своя кнопка **⬇ Скачать**.
Наведи мышку на строку — нужный плеер на странице обведётся рамкой.
Кнопка сверху качает сразу все.

## Если не получилось

| Что видишь | Что делать |
|---|---|
| «Программа-помощник не установлена» | Запусти установщик ещё раз (или `install.bat`, если ставил из исходников), потом в `chrome://extensions` нажми ⟳ на карточке расширения |
| «Видео не поймано» | Включи видео ▶, подожди пару секунд, открой окно снова |
| «Сайт не пустил» | Обнови страницу (F5), включи видео и скачай ещё раз |
| Предупреждение «видео защищено от копирования» или значок 🔒 у видео | Такое видео скачать нельзя |
| «Речи в видео не нашлось» | В записи нет слов (музыка, тишина) — текстового файла не будет. Если речь есть, выбери язык в ⚙ вручную и нажми «Скачать ещё раз» |
| «Готово не всё», «текст не получился» | Видео и звук на месте. Причина написана в строке загрузки; чаще всего не скачалась модель распознавания — проверь интернет и попроси текст ещё раз |
| «В эту папку нельзя записывать» | Выбери другую папку — например, в «Документах» или «Загрузках» |
| Что-то другое | У неудавшейся загрузки есть кнопка **Что пошло не так** — она открывает файл с подробностями |

## Благодарности и лицензии

Keeper использует чужие открытые разработки:

- [yt-dlp](https://github.com/yt-dlp/yt-dlp) — скачивание (Unlicense) и [ffmpeg](https://ffmpeg.org) — обработка видео и звука;
- [GigaAM v3](https://huggingface.co/ai-sage/GigaAM-v3) — распознавание русской речи, Сбер / SaluteDevices, лицензия MIT;
- [Parakeet TDT 0.6B v3](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3) — распознавание английского и европейских языков, NVIDIA, лицензия [CC-BY-4.0](https://creativecommons.org/licenses/by/4.0/); преобразование модели — проект k2-fsa;
- [Silero VAD](https://github.com/snakers4/silero-vad) — поиск речи в записи, лицензия MIT;
- [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) — запуск моделей, лицензия Apache-2.0.

Скачивай только то, на что у тебя есть право: свои видео и курсы, которые ты купил, для личного просмотра.
