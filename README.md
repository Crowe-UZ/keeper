# Качалка видео

Расширение для Chrome: скачивает видео с открытой вкладки в лучшем качестве.
Работает с YouTube, VK, Rutube, TikTok, Instagram и ещё с тысячей сайтов, а также с уроками купленных курсов.
Только для Windows.

## Установка (один раз, 5 минут)

1. Установи **Python 3.12** с [python.org](https://www.python.org/downloads/). В установщике поставь галочку **Add python.exe to PATH**.
2. Установи **ffmpeg** (склеивает видео и звук). Нажми `Win + R`, вставь строку и нажми Enter:
   ```
   winget install Gyan.FFmpeg
   ```
3. Скачай эту программу: зелёная кнопка **Code → Download ZIP** вверху страницы. Распакуй папку туда, где она будет лежать всегда.
4. В распакованной папке дважды щёлкни **`install.bat`** и дождись слова `Done`.
5. В Chrome открой `chrome://extensions`, включи справа вверху **Режим разработчика**, нажми
   **Загрузить распакованное расширение** и выбери папку **`extension`**.
6. Нажми на значок пазла справа от адресной строки и закрепи «Качалку видео» булавкой.

Папку после установки не переноси. Если перенёс — запусти `install.bat` ещё раз.

## Как пользоваться

1. Открой страницу с видео.
2. Нажми на значок качалки.
3. Нажми **⬇ Видео** (или **🎵 Звук**, если нужен только mp3).

Готовый файл появится в папке `Загрузки\Videos`. Папку можно поменять кнопкой **Сменить**.

Запускать ничего не нужно: программа включается сама и сама выключается, когда качать нечего.
Пока она работает, у часов виден её значок — через него можно открыть папку с видео или выйти.

Ещё в окне качалки:

- **Качество видео** — по умолчанию максимальное; можно ограничить (например, «до 720p»), чтобы файлы весили меньше.
- У загрузки есть **✕ Отмена**, у неудачной или отменённой — **↻ Повторить**.
- То, что уже скачано, второй раз не качается: качалка предупредит и предложит **Скачать ещё раз**.
- Когда видео готово, Windows покажет уведомление с кнопками **Открыть** и **Папка**.

### Если это урок курса или сайт, которого качалка не знает

Сначала **включи видео (▶)** и дай ему поиграть пару секунд, потом нажимай на значок.
На значке появится зелёная цифра — значит, видео поймано.

### Если на странице несколько видео

В окне будет список по порядку: «Видео 1», «Видео 2»… — с кадром из видео и названием, если оно подписано на странице.
У каждого своя кнопка **⬇ Видео**.
Наведи мышку на строку — нужный плеер на странице обведётся рамкой.
Кнопка сверху качает сразу все.

## Если не получилось

| Что видишь | Что делать |
|---|---|
| «Качалка не установлена» | Запусти `install.bat`, потом в `chrome://extensions` нажми ⟳ на карточке расширения |
| «Видео не поймано» | Включи видео ▶, подожди пару секунд, открой окно качалки снова |
| «Сайт не пустил» | Обнови страницу (F5), включи видео и скачай ещё раз |
| Красная надпись **DRM** | Видео защищено от копирования — скачать нельзя |
| Что-то другое | У загрузки в окне есть кнопка **Лог** — в этом файле написано, что пошло не так |

Скачивай только то, на что у тебя есть право: свои видео и курсы, которые ты купил, для личного просмотра.
