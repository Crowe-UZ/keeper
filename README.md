# Качалка видео

Скачивает видео с любой вкладки Chrome в максимальном качестве.

- **YouTube, VK, Rutube, TikTok, Instagram, Twitch и ещё 1000+ сайтов** — по ссылке страницы через yt-dlp.
- **Купленные курсы, сайты со встроенным плеером** — расширение «ловит» видеопоток (HLS/DASH/mp4), пока ролик играет,
  и передаёт его качалке вместе с твоим входом на сайт (cookies) и Referer.

Файлы: `%USERPROFILE%\Downloads\Videos`. Логи: `logs\` в этой папке.

## Установка (один раз)

1. Запустить `install.bat` — ставит библиотеки и прописывает качалку в Chrome (ключ в реестре текущего пользователя),
   чтобы расширение могло запускать её само.
2. `chrome://extensions` → включить **Режим разработчика** → **Загрузить распакованное расширение** → папка `extension`.
   После обновления файлов — нажать ⟳ на карточке расширения.
3. Закрепить значок (фиолетово-синий квадрат со стрелкой) на панели.

Папку `download_web` после установки не переносить — или запустить `install.bat` ещё раз.

## Каждый раз

На вкладке с видео нажать значок → **⬇ Видео** или **🎵 Звук**. Запускать ничего не нужно:

- качалка поднимается сама, без окна; пока она работает, у часов висит её значок (меню: папка с видео, логи, выход);
- 10 минут без загрузок и без открытого окна расширения — качалка сама закрывается и освобождает память;
- «Выход» в меню значка прерывает загрузки и убирает недокачанные куски;
- yt-dlp обновляется сам раз в сутки, перед запуском.

`start.bat` — запасной способ запустить качалку вручную, с окном (она тогда сама не закрывается).

### Курсы и «неизвестные» сайты

1. Открой урок и **нажми ▶** — пусть видео поиграет пару секунд. На значке появится зелёная цифра: столько потоков поймано.
2. Нажми значок → **⬇ Видео**. Качается поток, отмеченный ★ (мастер-плейлист = все качества, берётся лучшее).
3. Имя файла = заголовок вкладки.
4. Если видео на странице несколько — в окне список «Видео 1, Видео 2…» (по порядку на странице). У каждого свои кнопки
   **⬇ Видео** и **🎵**; наведи на строку — плеер подсветится на странице. Верхние кнопки качают все видео сразу,
   файлы называются «заголовок — видео N».
5. Красный значок / надпись DRM — видео защищено (Widevine и т.п.), такое скачать нельзя.

### Много видео сразу

Открой все нужные вкладки (для курсов — в каждой запусти ролик) → **Все вкладки (N)**. Одновременно качается 3, остальные в очереди.

### Правая кнопка мыши

«Скачать видео по ссылке» — по ссылке на странице, «Скачать видео с этой вкладки» — то же, что кнопка.

## Если что-то не так

- Кнопка **Логи** → `kachalka.log` — общий журнал: каждая задача, итог (реальное разрешение/кодек/битрейт) и ошибки.
- У каждой загрузки в окне есть ссылка **лог** → подробности именно этой загрузки: что поймало расширение
  и почему выбрало этот поток, какие форматы были доступны, какой выбран, полный вывод yt-dlp, ffprobe итога.
- Значения cookies в логи не пишутся, только имена.
- Скинь Claude файл лога задачи — по нему видно, где сломалось.

Частые ошибки:

| Сообщение | Что делать |
|---|---|
| Качалка не установлена | запустить `install.bat`, потом ⟳ на карточке расширения |
| Качалка не запустилась | смотреть `logs\launcher.log` и `logs\kachalka.log`; запасной путь — `start.bat` |
| Не могу занять порт 5577 | качалка уже запущена — лишнюю закрыть через значок у часов |
| На странице не нашлось видео | включить ролик ▶, подождать, скачать снова |
| Сайт не пустил | обновить страницу (ссылки на курсах временные), включить видео, скачать снова |
| DRM | скачать нельзя |

## Устройство

- `server.py` — локальный сервер на `127.0.0.1:5577`, принимает команды только от расширений Chrome, качает через yt-dlp,
  склеивает ffmpeg'ом. Для YouTube использует JS-движок (node), иначе часть форматов (4K) недоступна.
- `extension/` — расширение Chrome (MV3): `background.js` ловит потоки, `popup.*` — окно, `common.js` — выбор, что качать.
- `launcher.py` + `host.bat` — мост для Chrome (native messaging): расширение зовёт, он поднимает `server.py` в фоне.
- `install.bat` — создаёт `.venv` (Python 3.12), ставит yt-dlp/pystray/pillow, прописывает мост в Chrome.
- `start.bat` — ручной запуск сервера с окном.
